# Godot-JVM

Write Godot game and application logic in Kotlin, Java, or Scala with the official editor. Begin with [Start here](start/index.md) to set up a project, run a script, and export a game.

Godot-JVM 1.0.0 is production-ready. We welcome feedback as we continue improving the project and its API.

## Requirements

Use Godot 4.7.2 or newer and JDK 17 or newer. Tool scripts, editor addons, and web exports are not supported yet; [Known limitations](troubleshooting/known-limitations.md) covers the remaining constraints.
