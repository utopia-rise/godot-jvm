# User guide

The guide assumes a working project from [Your first script](../start/your-first-script.md), familiarity with Godot, and IntelliJ IDEA with the Godot-JVM plugin. Examples use the same `Player` theme, but each page stands on its own. Gradle configuration uses `build.gradle.kts` for all three languages.
