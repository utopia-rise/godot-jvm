# Introduction

Write Godot scripts in Kotlin, Java, or Scala with the official editor. Godot-JVM runs a JVM through a GDExtension addon: annotate your classes, compile them with Gradle, and attach their source files to nodes.

## What these docs assume

You should know the Godot editor and at least one of Kotlin, Java, or Scala. These pages explain what Godot-JVM adds, including registration, builds, and access to the Godot API. Choose your language's tab in each example.

For background on the tools and languages:

- [Godot's Step by step tutorial](https://docs.godotengine.org/en/stable/getting_started/step_by_step/index.html)
- [Kotlin's Getting Started guide](https://kotlinlang.org/docs/getting-started.html)
- [dev.java's Learn section](https://dev.java/learn/)
- [Scala's Getting Started guide](https://docs.scala-lang.org/getting-started/index.html)

Next, install a JDK and the addon.
