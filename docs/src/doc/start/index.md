# Start here

This track takes you from a bare Godot project to a running Kotlin, Java, or
Scala script attached to a node. Read the pages in order:

1. [Introduction](introduction.md) — what Godot-JVM is, what this track will
   have you do, and the Godot/Kotlin/Java/Scala knowledge it assumes.
2. [Install a JDK](install-a-jdk.md) — get a JDK 17+ installed and make it
   available through `PATH` or `JAVA_HOME`.
3. [Install the addon](install-the-addon.md) — download the Godot-JVM
   GDExtension addon into a Godot project.
4. [Create a project](create-a-project.md) — generate the Gradle build and
   source layout.
5. [Project layout](project-layout.md) — where source files live once the
   project exists.
6. [Your first script](your-first-script.md) — write, build, and attach a
   class to a node.
7. [Export a test build](export-a-test-build.md) — prove the pipeline works
   outside the editor too.

By the end of this track you will have a Godot project with a working
Gradle build, one script running in the scene tree, and one exported build
that ran it too.
