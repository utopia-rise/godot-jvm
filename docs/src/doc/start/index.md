# Start here

Set up Godot-JVM and run a script. Check [Compatibility and requirements](compatibility.md) for supported versions and platforms, then follow these pages in order:

1. [Introduction](introduction.md): what Godot-JVM adds and what you'll need to know.
2. [Install](install.md): install a JDK 17 or newer.
3. [Create a project](create-a-project.md): start from the Godot editor, IntelliJ IDEA or
   the template, and learn where everything lives.
4. [Your first script](your-first-script.md): write, build, and attach a
   class to a node, then run it.

By the end, you'll have a working Gradle project and a script running in a scene.
