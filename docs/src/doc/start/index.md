# Start here

Set up Godot-JVM, run a script, and export a desktop build. Follow these pages in order:

1. [Introduction](introduction.md): what Godot-JVM adds and what you'll need to know.
2. [Install](install.md): install a JDK 17 or newer and add the Godot-JVM addon to your project.
3. [Create a project](create-a-project.md): generate the Gradle build and
   source layout.
4. [Project layout](project-layout.md): where source files live once the
   project exists.
5. [Your first script](your-first-script.md): write, build, and attach a
   class to a node.
6. [Export a test build](export-a-test-build.md): run your project outside the editor.

By the end, you'll have a working Gradle project, a script running in a scene, and a desktop export.
