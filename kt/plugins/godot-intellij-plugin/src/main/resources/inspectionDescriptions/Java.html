Checks Java declarations used by Godot-JVM registration.

Current Java checks include:

  • registered classes must inherit a Godot type and cannot be generic
  • concrete registered classes must expose a parameterless constructor
  • registered class names must be unique
  • classes containing registered fields, signals, or methods must themselves be registered
  • registered methods cannot be generic or exceed Godot's parameter limit
  • Godot lifecycle overrides require explicit registration in explicit mode

Class and method selection follows the configured explicit, inferred, or automatic annotation processing mode. Kotlin-specific property, signal, RPC, and callable-reference checks are not applied to Java.
