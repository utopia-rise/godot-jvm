Checks Kotlin declarations used by Godot-JVM registration.

Current Kotlin checks include:

  • registered class inheritance, generics, parameterless constructors, and unique names
  • class, property, signal, and method selection for the configured registration mode
  • @Visible, @Export, property type, nullability, and hint validation
  • @Emit signal type and mutability validation
  • @Register, lifecycle override, and method parameter validation
  • @Rpc configuration validation
  • callable-reference validation for signals, call, and rpc

The inspection uses Kotlin PSI and K2 analysis. Annotation selection follows the configured explicit, inferred, or automatic annotation processing mode, including recursive meta-annotations where supported.
