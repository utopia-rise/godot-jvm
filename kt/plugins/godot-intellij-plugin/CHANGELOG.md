# Changelog

## [Unreleased]

First release of the Godot-JVM plugin: write your Godot scripts in Kotlin, Java or Scala with IntelliJ IDEA.

- Create a new Godot-JVM project, or add Godot-JVM to an existing one, with optional Android and iOS setup.
- Create a Godot script in a few clicks: pick the language, the Godot class to extend and the functions to override.
- Start the Godot editor or your game straight from IntelliJ IDEA, with the JDK of your choice.
- Get told in the editor when a script, property, function or signal cannot be used by Godot, with quick fixes for the most common mistakes.
- See at a glance which parts of your scripts Godot will use, thanks to discreet highlighting you can turn off.
